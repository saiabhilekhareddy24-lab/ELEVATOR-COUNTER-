# Elevator Counter using Java

## Project Description

The Elevator Counter is a simple Java-based project that keeps track of
the number of people inside an elevator.

The system increases the counter when a person enters and decreases the
counter when a person exits. It also checks whether the elevator has
reached its maximum capacity.

## Features

- Counts people entering the elevator.
- Counts people exiting the elevator.
- Displays the current number of people.
- Prevents entry when the elevator is full.
- Detects whether the elevator is empty.
- Detects whether the elevator is full.

## Technologies Used

- Java
- Object-Oriented Programming
- Java Testbench
